# Calculator

## Description

A simple command-line calculator built in Python for beginners.
It shows a menu, asks for two numbers, and performs the chosen
operation. It keeps running until you choose to exit.

## Features

- Add, subtract, multiply, divide
- Handles division by zero without crashing
- Handles text typed where a number was expected
- Runs in a loop until you exit

## Concepts Used

- Variables
- User input with `input()`
- Converting text to numbers with `int()`
- `if` / `elif` / `else`
- Arithmetic operators
- `while` loop
- `break` and `continue`
- Error handling with `try` / `except`

## How to Run

```bash
python calculator.py
```

## What I Learned

- Taking input from the user and converting it to a number
- Using conditional statements to choose between actions
- Keeping a program running with a `while` loop
- Catching errors with `try` / `except` so the program doesn't crash
- Using `continue` to restart the loop after bad input
