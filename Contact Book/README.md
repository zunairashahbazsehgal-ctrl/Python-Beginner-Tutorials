# Contact Book

A simple command-line Contact Book built with Python. This beginner-friendly project allows users to store, view, search, and delete contacts using a text file.

## Features

* Add a new contact
* View all saved contacts
* Search for a contact by name
* Delete a contact
* Store contact information in a text file

## Technologies Used

* Python 3
* File Handling
* Functions
* Loops
* Conditional Statements

## Project Structure

```
Contact_Book/
│── contact_book.py
│── contacts.txt
│── README.md
```

## How to Run

1. Clone this repository.
2. Open the project in Visual Studio Code or any Python IDE.
3. Run `contact_book.py`.
4. Choose an option from the menu.

## Learning Objectives

This project helps beginners practice:

* Working with functions
* Reading and writing text files
* Using loops and conditional statements
* Taking user input
* Building a simple menu-driven application
