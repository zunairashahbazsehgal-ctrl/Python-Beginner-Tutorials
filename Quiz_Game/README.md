# Quiz Game

A simple and beginner-friendly Quiz Game built with Python.

This project asks multiple-choice questions, checks the user's answers, calculates the final score, and lets the player play again.

---

## Features

• Multiple-choice questions

• Instant answer checking

• Score tracking

• Play Again option

• Beginner-friendly code

---

## Python Concepts Used

• Variables

• User Input (`input()`)

• `if`, `elif`, and `else`

• `while` loop

• String methods (`lower()`, `strip()`)

• `break` and `continue`

## How to Run

1. Ensure you have Python installed on your machine.
2. Clone this repository or download the script.
3. Open your terminal or command prompt.
4. Run the following command:

```bash
python main.py
```
