# Student Result System

## Description

A simple command-line application built in Python for beginners.
The program collects a student's marks for three subjects,
calculates the total and average marks, assigns a grade,
and displays a formatted student report.

## Features

- Enter student name and marks for three subjects
- Calculates total marks automatically
- Calculates average marks
- Assigns a grade based on the average
- Displays a clear and formatted student report
- Function-based program structure

## Concepts Used

- Variables
- User input with `input()`
- Functions
- Function parameters
- Arithmetic operators
- `if` / `elif` / `else`
- Comparison operators
- f-strings
- Printing formatted output

## How to Run

```bash
python student_result_system.py
```

## How It Works

The program first asks the user to enter the student's name
followed by marks for English, Math, and Science.

It calculates the total marks, then finds the average by
dividing the total by the number of subjects.

Based on the average marks, the program assigns a grade
using `if` / `elif` / `else` conditions and finally displays
the complete student report.
