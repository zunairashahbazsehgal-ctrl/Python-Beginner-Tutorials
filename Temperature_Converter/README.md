# Temperature Converter

A simple, interactive command-line application built in Python that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Interactive Menu: Easily switch between different conversion types.
- Continuous Loop: Perform multiple conversions without restarting the program.
- Input Validation: Gracefully handles invalid numeric inputs.

## How to Run

1. Ensure you have Python installed on your machine.
2. Clone this repository or download the script.
3. Open your terminal or command prompt.
4. Run the following command:

```bash
python main.py
```

## Concepts Used

- `while` loops for continuous execution.
- `if/elif/else` statements for control flow.
- `try/except` blocks for error handling (to catch invalid inputs).
- Python functions for modular code structure.

## Usage

When the program runs, you will see a menu:

1. Choose an option (1–3) to convert.
2. Enter the temperature value when prompted.
3. Select **4** to exit the application.
