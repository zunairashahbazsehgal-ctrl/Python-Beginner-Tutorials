# USD to PKR Converter

## Description

A simple Python program for beginners.
You type in an amount in US Dollars, and it tells you
how many Pakistani Rupees that is.

## Concepts Used

- Variables
- Functions
- User input
- `float()`
- Multiplication

## How to Run

```bash
python converter.py
```

## Example

Enter USD amount: 50
PKR = 13900.0


## How It Works

The program asks you for a number.

Then it multiplies that number by 278, because
1 US Dollar is about 278 Pakistani Rupees.

Then it prints the answer.

We use `float()` instead of `int()` because money can
have decimals, like 12.50.
